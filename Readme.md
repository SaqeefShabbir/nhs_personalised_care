# NHS Personalised Care System

## Overview
A comprehensive healthcare management platform implementing the NHS England Comprehensive Model for Personalised Care with AI-powered insights.

## Features
- ✅ Patient Management with NHS numbers
- ✅ Personalised Care Plans with goals and outcomes
- ✅ Patient Activation Measure (PAM) tracking
- ✅ AI-powered risk prediction and insights
- ✅ Clinical notes with NLP sentiment analysis
- ✅ Shared decision-making documentation
- ✅ Progressive Web App (PWA) for mobile
- ✅ Offline-first architecture
- ✅ Real-time WebSocket updates
